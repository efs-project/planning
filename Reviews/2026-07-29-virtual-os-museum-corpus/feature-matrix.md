## The three structural differences (not features)

1. **Distribution model.** VOM moves the whole museum to you (hypervisor + 184 GB); EFS would move the *minimum closure per exhibit* (measured: ~2.5 MB + streamed chunks for System 7). Neither dominates: VOM wins fidelity and breadth; EFS wins funnel, mobile, links, and marginal cost.
2. **Trust model.** VOM = trust the curator + SHA256 + an unpublished GPG key; EFS = verified bytes from interchangeable mirrors + signed claims + reader-chosen lenses. VOM's model cannot express "two curators disagree about whether this install works"; EFS's is built for it.
3. **Liability model.** VOM = one Canadian on income support accepting personal takedown exposure, hosted by IA's forbearance; EFS = permanent unattributed bytes with **no takedown at the protocol layer** and filtering only at lens/gateway edges. EFS cannot copy VOM's content posture; it must choose its own (owner decision; see [`open-questions.md`](./open-questions.md)).
