# R11b — Historical July client/OS round, part 2 (packages, persistence, wallet, SDK, Files bar, app-model handoff, agent-native, network privacy, threat model) against the current web-client-os spine

Lane: `R11b-clientv2-packages-wallet-sdk-threat` · Reviewer date 2026-09-02 · Vault read-only.

## 0. Headline

The nine `Designs/clientv2/` documents in this lane are the July 2026 Web-OS round's mechanism layer: they specify a fixed-ring OS (Bootstrapper → Kernel → System Chrome → Shell → Ring-3 apps) with EFS-is-the-registry packages, a four-tier browser persistence model, Kernel-held persona keys and a System Chrome signing ceremony, a two-package SDK, a Kernel network broker, a CaMeL-shaped agent pipeline, and a consolidated threat model. The owner retired that architecture as "evidence, not adopted" on 2026-08-12 (`Designs/efsv2/owner-rulings.md` §2026-08-12; `Designs/clientv2/README.md` banner), and the current spine (`Designs/web-client-os/README.md` §Historical Client/OS audit) dispositions each area as Retain / Revise / Retire. The spine retained almost every *requirement* (exact releases, capability ports, storage-loss honesty, agent parity, no ambient network) and replaced almost every *mechanism*. Three things fell through the seam: (1) no current threat model exists for the guest-read + basic-write MVP — only a trusted/untrusted list; (2) the write ceremony is specified as obligations spread across three docs but nowhere as what a person actually sees and signs; (3) the ArDrive-derived Files feature bar (15 MATCH / 14 DIFFER / 19 acceptance tests) has no disposition row at all, and roughly two-thirds of it vanished silently. Separately, the SDK for v2 does not exist as a design — the spine names a "Protocol SDK" and an "OS runtime SDK" as logical boundaries and defers their design to a document that has not been written. Cohesion inside the historical set is high (it was internally reconciled); cohesion between historical and current is exactly what the README audit table says it is, except where the audit table is silent.
