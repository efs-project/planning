About this experiment

Prototype only. The two folders are explicit ID mounts, not proven nested paths. Names use lowercase ASCII a–z 0–9 . _ -. Inline record bodies are limited to 8192 bytes: 8160 document bytes for a new file and 8128 for edits.

Read-back is RPC-observed, not a state proof or finality guarantee. No MIME metadata is asserted: UTF-8 may be previewed as plain text; downloads preserve the verified bytes. Conflict review compares file HEADs; folder placement still uses Alice-first order.

Demo signers are public, disposable local-test keys, loaded only on request and never saved by this screen. No real-wallet connection is implemented. Removing a placement masks a name in the signer's Lens; it does not erase history. Revision history below is locally witnessed, not exhaustive.
