# Offline raw-packet audit boundary

`audit.mjs` is independently authored against frozen `expectations-node26.json`, SHA-256 `0b26e6d2a0037de6f89089eece41cbb1174a76eb87e8de945d9c599bf8b28622`. It does not import the candidate runner, preparation generator, candidate ABI or candidate assertions. Only the runner's transport/report schema was inspected. Expected state bytes remain the reviewed pre-run JSON. Calibration's static `(publication=2, firstAdmission=4)` result is encoded from the already sealed control ordinals and the production `executeSigned` return ABI.

Usage: `/opt/homebrew/bin/node audit.mjs <result-directory> <expectations-node26.json>`; emits JSON to stdout, performs no RPC, compilation or filesystem write. Exit 0 means `PASS_RPC_OBSERVED`; any missing field, mismatch or unsupported promised transport fact produces exit 1 / `FAIL_OR_GAP` with its first failing assertion. Do not count unchecked later assertions after a failure as passes.

Checks cover all 528 prescribed raw return values (69 main +19 auxiliary, twice, three arms), exact target/calldata/number-qualified basis, pre-after-prefix and post-after-receipt ordering; 36 signed transaction hashes and recovered senders, nonce/destination/calldata/chain/value/gas/signature joins; 18 CREATE and initcode/runtime pins; receipts/status/consumed gas and a contiguous 0–36 header/parent chain; three exact static-to-mined input/error links; and raw/report correlation. Deployment/setup/attempt gas limits 15m/8m/3m are the sealed runner envelope, not a protocol cost claim. All report booleans are ignored as evidence.

Limits are explicit in audit output. Numeric-block `eth_call` records can be joined to retained headers/receipt hashes, but do not supply EIP-1898 hash-qualified calls, Merkle state proofs or trusted consensus. The audit requires the complete literal Anvil `error.data`; it never extracts bytes from human error text. Runtime byte hashes are observations compared with prior independently derived pins; RPC cannot prove compiler/source provenance or internal mutation order. Those remain separate root-reviewed inputs. No C equivalence, portability proof or normal paid-cost conclusion follows.

Before the actual run, only syntax was checked. The auditor has not been executed against a candidate packet or a fabricated passing packet; root must retain its outcome and review any strict transport assumption that fails without changing frozen expected answers.
