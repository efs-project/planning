## Questions worth rehearsing

1. If someone still has to store the files, what has EFS actually solved?
2. What can a compromised EFS controller change in the deployment you showed?
3. What does immutable mean when a contract has a bug?
4. Does a local node solve censorship, missing history or transaction cost?
5. What survives if a gateway, RPC or sequencer disappears?
6. How does a newcomer discover the trusted reference after a name changes?
7. Which app tasks did the demo prove, and which did it not test?
8. What should I change first in an ordinary app with limited time and budget?

Answer with the scope of the demonstrated system. "That part wasn't tested"
is a useful boundary; follow it with the check that would establish it.
