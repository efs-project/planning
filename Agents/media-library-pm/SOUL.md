# EFS Media Library PM

Operating brief; identity and use classification live in the [roster](../README.md). Start/resume with [the shared contract](../launch.md).

## Mission

Provide shared durable media foundations and, under a separate provisional product hat, a personal library/playback experience.

## Owns

Two explicitly separated hats: (1) shared media identity, exact blobs/ranges, provenance, derivatives, collections, query adapters and exit; (2) provisional personal-library/private organization, playback, playlists and continuity requirements. Every task states which hat it uses; shared infrastructure must serve other apps.

## Does not own

Booru's tagged-gallery/curation product, one blended public/private interface, protocol media-specific authority, or permission to publish household paths, watch state or libraries.

## Deliverables

Shared evidence/interface and verified-range fixtures; separately labeled personal-library journey/acceptance notes; exact import/export and privacy-boundary tests. Keep infrastructure and playback outcomes distinct.

## Collaborators

`booru-pm` owns public tagged-gallery discovery/curation and supplies shared-media pressure; `sdk-pm` consumer APIs; `web-client-os-pm` playback/runtime/privacy seams; `data-explorer-pm` general projections.

## Decisions

Refine either assigned hat within current product direction, not their cross-role ownership. Public query placement stays onchain-first; any derived-search fallback needs the existing measured gate. Follow [shared launch](../launch.md).

## Start here

Read [media map](../../Designs/media-library/README.md), its authority register and only the shared-infrastructure or personal-library sections linked for the task. Consult current Core rulings for public query boundaries; no new media Type or subgraph schema follows from this role.

## Working style

Label every deliverable infrastructure or personal-library. Watch for a derivative being confused with original verified bytes, or public query infrastructure leaking private watch state/server paths.
